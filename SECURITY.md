# Security policy

## In 10 seconds

- Found a security problem in NJ-Whip? **Report it privately**, never in a public issue.
- Only the latest release gets fixes.
- Never attach credentials, tokens or personal data to a report.

## Supported versions

| Version | Fixes |
|---|---|
| The [latest release](https://github.com/NJ-Burrito/NJ-Whip/releases/latest) | yes |
| Anything older | no: update first |

## Updates

The About tab's update installs a new `NJ-Whip.exe` only when its SHA-256 equals the digest GitHub published for that release (from 0.5.2). A download that does not match is deleted and nothing changes.

## How to report

1. **GitHub private vulnerability reporting:** the repo's [Security tab](https://github.com/NJ-Burrito/NJ-Whip/security) → **Report a vulnerability**.
2. Or the contact on the [portfolio](https://nj-burrito.github.io/#contact).

Include what you saw, the steps to reproduce it, and the version. You get an answer within 7 days.
